# uno-pysdr-csharp-guide
pysdr.org examples, written on uno platform and C# language desktop oriented

Create env python

1. Create a virtual environment (you only need to do this once per project) 
`python3 -m venv venv`
2. Activate the virtual environment
`source venv/bin/activate  # On Linux/macOS`
`./venv/Scripts/activate # On Windows`
3. Now that the virtual environment is active, use 
pip to install the package pip install git+https://github.com/GvozdevLeonid/python_hackrf.git  
`pip install scipy`
`pip install matplotlib`
4. When you're finished working in this project, you can deactivate the environment 
deactivate 
5. Run file
`py file.py`
